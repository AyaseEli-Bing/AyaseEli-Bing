## 关于我 | About Me

**中文**

我主要在做两类事情：一类是系统级工具和原生应用开发，围绕高性能、底层优化和用户体验持续打磨，包含 [`xnumeter`](https://github.com/AyaseEli-Bing/xnumeter)、[`heatpeek`](https://github.com/AyaseEli-Bing/heatpeek) 等；另一类是自动化脚本和基础设施搭建，例如 [`Mac-Arch-Installer`](https://github.com/AyaseEli-Bing/Mac-Arch-Installer) 等。

我希望把复杂的技术能力打磨成真正稳定、好用、可落地的工具，也长期关注 C/C++ 系统编程、Python 自动化、跨平台开发等方向；同时，我也对软硬件结合的场景保持浓厚兴趣，比如 macOS 菜单栏工具、系统监控、温度传感器读取等。目前我在持续完善现有项目并探索新的技术方向，欢迎开源项目与我一起贡献代码、攻克难题、完善工具链。

我的梦想，是构建出真正能提升开发者效率的工具链。

**English**

I mainly work across two areas: system-level tools and native application development around high performance, low-level optimization, and user experience, including [`xnumeter`](https://github.com/AyaseEli-Bing/xnumeter) and [`heatpeek`](https://github.com/AyaseEli-Bing/heatpeek); and automation scripts and infrastructure setup such as [`Mac-Arch-Installer`](https://github.com/AyaseEli-Bing/Mac-Arch-Installer).

I want to turn complex technical capabilities into stable, useful, and shippable tools. I am especially interested in C/C++ system programming, Python automation, cross-platform development, and I am also drawn to software-hardware integration scenarios such as macOS menu bar utilities, system monitoring, and temperature sensor reading. I am continuously improving existing projects and exploring new technical directions, and I welcome open-source collaboration on code contributions, problem-solving, and toolchain enhancement.

My dream is to build toolchains that truly improve developer productivity.
